# bic21203-lab4b-json-jquery
Create a valid books.json (two-book array with typed fields), load it in books.html via fetch() with async/await and error handling to display the first title, second author, and genres by book, and build jquery-dom.html using jQuery 4.0.0's .text(), .addClass(), and .on("click", ...) as equivalents to three native DOM operations.
